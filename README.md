# 사주팔자 (Saju)

생년월일시로 사주팔자를 풀어보는 만세력 웹사이트입니다. GitHub Pages로 배포됩니다.

## 특징

- **정확한 만세력 계산**: 24절기를 천문 공식(태양 황경)으로 직접 계산해 년주·월주를 정합니다. 입춘 시각 오차 ±수 분 수준.
- **일주 계산**: 1900-01-01 갑술일 앵커 기반 60갑자 순환 (외부 만세력과 교차 검증됨).
- **한국 음력 지원**: 삭망월을 천문 계산으로 구하고, 중기 없는 달을 윤달로 판정하는 한국식 음력→양력 변환 (1900~2100년).
- **십성·합충·삼합·대운**: 일간 기준 십성, 지지의 육합·육충·삼합, 순행/역행 대운(10년 주기) 제공.
- **일간 풀이**: 10개 천간별 성격 풀이와 오행 분포 분석.
- 순수 HTML/CSS/JS, 빌드 과정 없음 — 정적 호스팅 어디서든 동작합니다.

## 구조

```
index.html        입력 폼 + 결과 화면
css/style.css     다크 테마 스타일
js/saju.js        사주 계산 엔진 (절기/사주/십성/대운/음력)
js/app.js         UI 로직 + 해석 콘텐츠
```

## 로컬에서 열기

별도 서버 없이 `index.html`을 브라우저에서 열면 됩니다.
